# gtalmor/tap

Homebrew tap for [Assume Cloaker](https://github.com/gtalmor/assume-cloaker), a macOS menu bar app that
keeps Keycloak (saml2aws) and AWS SSO sessions alive.

```bash
brew install --cask gtalmor/tap/assume-cloaker
```

Updates: the app updates itself through Homebrew, or run `brew upgrade --cask assume-cloaker`.

`teams/` holds encrypted team configurations; they can only be opened with an invite from the team.
